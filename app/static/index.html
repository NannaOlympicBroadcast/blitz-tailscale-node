🌍 方式二：全局 Exit Node

系统全局分流

作为 Tailscale 官方 Exit Node，接管整机流量（出口 IP 为德国 Hetzner）：

  1. 前往 Tailscale 管理后台
  2. 找到本节点 blitz-de-exit
  3. 点击 ... ➔ 批准 Use as exit node
  4. 客户端执行: tailscale set --exit-node=blitz-de-exit
